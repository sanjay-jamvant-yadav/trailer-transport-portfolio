# Shreya Transport — Portfolio Website

Mobile-first static website built with:
- HTML5
- CSS3
- Alpine.js
- No build step

## Cloudflare Pages

Recommended settings:
- Production branch: `main`
- Framework preset: None
- Build command: leave blank
- Build output directory: `/`

Push this repository to GitHub and connect it to Cloudflare Pages.

## Before launch

1. Replace `images/transport-collage.png` if you have real company/trailer photos.
2. Confirm the phone and WhatsApp numbers.
3. Confirm the business name and address.
4. Add your final custom domain in Cloudflare.
5. Add `sitemap.xml` and update the canonical URL once the domain is known.

## Important

The generated image is intended as a visual placeholder. For a Google Business Profile and the website, real photos of your trailers, cargo, office, and operations are preferable when available.
