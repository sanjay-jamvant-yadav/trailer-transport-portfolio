# Shreya Transport Portfolio

Mobile-first static website for Shreya Transport.

## Main idea

All editable business/content information is in:

`js/site-data.js`

Update that object and the website pages will use the new values automatically.

## Pages

- Home — `index.html`
- Services — `services.html`
- About Us — `about.html`
- Gallery — `gallery.html`
- Contact — `contact.html`

## Important

The current gallery image is a temporary AI/placeholder image. Replace it later with real business photographs.

The contact form currently opens WhatsApp; no backend/database is connected.
